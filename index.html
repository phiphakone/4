Bubble Sort (Sắp xếp nổi bọt)

Bài thuyết trình nhóm – khoảng 10 người lần lượt trình bày

Từ ý tưởng

So sánh cặp liền kề và đổi chỗ nếu sai thứ tự. Số lớn sẽ “nổi” dần lên cuối. Cờ swapped giúp dừng sớm → tốt nhất O(n).

Khi nào nên dùng / không nên dùng

Phù hợp học lần đầu, mảng rất nhỏ. Không phù hợp dữ liệu lớn vì O(n²) — số so sánh khoảng n × n.

✓ Phù hợp khi

  • Học thuật toán lần đầu
  • Mảng rất nhỏ
  • Cần ổn định + code đơn giản

✗ Không phù hợp khi

  • Dữ liệu lớn
  • Yêu cầu hiệu suất

Thuật toán chi tiết

Bước 1: i chạy từ 0 đến n−2.

Bước 2: swapped ← false.

Bước 3: j chạy từ 0 đến n−i−2. Nếu a[j] > a[j+1] thì đổi chỗ.

Bước 4: Nếu swapped vẫn false thì break.

Sơ đồ minh họa từng bước

Mảng 5, 1, 4, 2, 8. Mỗi vòng số lớn nhất nổi về cuối.

Ban đầu

Mã giả & Cài đặt C++

procedure BubbleSort(a[0..n−1])      // bắt đầu sắp xếp nổi bọt
  for i ← 0 to n−2 do                // số vòng nổi bọt
    swapped ← false                  // chưa đổi chỗ vòng này
    for j ← 0 to n−i−2 do            // so sánh từng cặp liền kề
      if a[j] > a[j+1] then          // cặp đứng sai thứ tự?
        swap a[j] with a[j+1]        // đổi chỗ, số lớn nổi sang phải
        swapped ← true               // đánh dấu đã đổi
      end if
    end for
    if not swapped then break        // không đổi nữa → đã sắp, dừng
  end for
end procedure
void bubbleSort(int a[], int n) {          // hàm C++
  for (int i = 0; i < n - 1; i++) {        // vòng ngoài
    bool swapped = false;                  // cờ đã đổi chỗ
    for (int j = 0; j < n - i - 1; j++) {  // cặp liền kề
      if (a[j] > a[j + 1]) {               // sai thứ tự
        int temp = a[j];                   // đổi chỗ bằng temp
        a[j] = a[j + 1];
        a[j + 1] = temp;
        swapped = true;                    // đã có đổi
      }
    }
    if (!swapped) break;                   // dừng sớm
  }
}
procedure / hàm: bắt đầu Bubble Sort
for i: mỗi vòng đẩy số lớn nhất ra cuối
swapped: cờ kiểm tra có đổi chỗ không
for j: duyệt từng cặp liền kề
if a[j] > a[j+1]: sai thứ tự thì đổi
if not swapped then break: đã sắp xong thì dừng sớm

Mô hình ví dụ – Sinh viên

Sau Bubble Sort: Lê Văn C 6.8 → Nguyễn Văn A 7.5 → Trần Thị B 8.2 → Phạm Thị D 9.0.

Ưu điểm

Dễ hiểu, ổn định, có thể dừng sớm → O(n).

Nhược điểm

O(n²) khi dữ liệu lớn. Ít dùng thực tế.

Kết luận

Bubble Sort dễ hiểu nhất nhưng chậm vì O(n²). Nhóm em xin cảm ơn thầy cô và các bạn.
