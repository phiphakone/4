Bubble Sort (Sắp xếp nổi bọt)

Bài thuyết trình nhóm – khoảng 10 người lần lượt trình bày

Cuộn xuống để bắt đầu

Từ ý tưởng

Ý tưởng: so sánh từng cặp phần tử liền kề và đổi chỗ nếu sai thứ tự. Phần tử lớn nhất sẽ “nổi” dần lên cuối mảng như bọt khí nổi lên mặt nước.

Mỗi vòng duyệt, phần tử lớn nhất trong đoạn chưa sắp sẽ về đúng vị trí cuối. Có thể tối ưu bằng cờ swapped (nghĩa là “đã đổi chỗ”): nếu một vòng không còn đổi chỗ thì dừng sớm. Khi đó độ phức tạp tốt nhất là O(n). O(n) nghĩa là thời gian chạy tăng gần đúng bằng số phần tử n — ví dụ 100 phần tử thì khoảng 100 bước, nên nhanh. Trường hợp này xảy ra khi mảng đã sắp sẵn.

Khi nào nên dùng / không nên dùng

Bubble Sort phù hợp khi học thuật toán lần đầu, mảng rất nhỏ, cần ổn định và code đơn giản. Không phù hợp với dữ liệu lớn vì độ phức tạp là O(n²). Chữ O (Big O) dùng để đo thời gian chạy. O(n²) nghĩa là số lần so sánh khoảng n × n (n bình phương). Ví dụ 100 phần tử ≈ 10.000 lần so sánh — càng nhiều dữ liệu càng chậm rất nhanh.

✓ Phù hợp khi

  • Học thuật toán lần đầu
  • Mảng rất nhỏ
  • Cần ổn định + code đơn giản

✗ Không phù hợp khi

  • Dữ liệu lớn
  • Yêu cầu hiệu suất
  • Hầu hết ứng dụng thực tế

Thuật toán chi tiết

Bước 1: i chạy từ 0 đến n−2 – số vòng “nổi bọt”.

Bước 2: Đặt swapped ← false ở đầu mỗi vòng.

Bước 3: j chạy từ 0 đến n−i−2. Nếu a[j] > a[j+1] thì đổi chỗ và swapped ← true.

Bước 4: Nếu swapped vẫn false thì break – mảng đã sắp, dừng sớm.

Sơ đồ minh họa từng bước

Minh họa với mảng 5, 1, 4, 2, 8.

Vòng 1: các cặp liền kề đổi chỗ → 8 nổi về cuối. Vòng 2: tiếp tục → 5 về đúng chỗ. Vòng 3: không còn đổi → dừng sớm.

Ban đầu

Mã giả & Cài đặt C++

Có vòng ngoài, cờ swapped, vòng trong so sánh cặp liền kề, và break khi không còn đổi chỗ. break sớm giúp đạt O(n) (khoảng n bước, nhanh) khi đã sắp sẵn.

procedure BubbleSort(a[0..n−1])
  for i ← 0 to n−2 do
    swapped ← false
    for j ← 0 to n−i−2 do
      if a[j] > a[j+1] then
        swap a[j] with a[j+1]
        swapped ← true
      end if
    end for
    if not swapped then break
  end for
end procedure
void bubbleSort(int a[], int n) {
  for (int i = 0; i < n - 1; i++) {
    bool swapped = false;
    for (int j = 0; j < n - i - 1; j++) {
      if (a[j] > a[j + 1]) {
        int temp = a[j];
        a[j] = a[j + 1];
        a[j + 1] = temp;
        swapped = true;
      }
    }
    if (!swapped) break;
  }
}

Ưu điểm

Rất dễ hiểu và cài đặt. Ổn định (stable). Có thể tối ưu dừng sớm → O(n) tốt nhất (khoảng n bước, nhanh). Không cần bộ nhớ phụ.

  • Rất dễ hiểu và cài đặt
  • Ổn định (stable)
  • Có thể dừng sớm → O(n) (≈ n bước)
  • Không cần bộ nhớ phụ

Nhược điểm

O(n²) (số bước ≈ n × n) — chậm với dữ liệu lớn. Số lần so sánh và đổi chỗ nhiều. Ít được dùng trong thực tế – chủ yếu dùng trong giáo dục.

  • O(n²) — số bước ≈ n × n, chậm với dữ liệu lớn
  • Số lần so sánh và đổi chỗ nhiều
  • Ít được dùng trong thực tế

Kết luận

Bubble Sort (Sắp xếp nổi bọt) dễ hiểu nhất nhưng hiệu suất kém vì O(n²) (số bước ≈ n × n). Nên học để nắm ý tưởng, sau đó chuyển sang thuật toán tốt hơn.
