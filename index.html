Bubble Sort (Sắp xếp nổi bọt)

Bài thuyết trình nhóm

Từ ý tưởng

So sánh từng cặp liền kề và đổi chỗ nếu sai thứ tự. Phần tử lớn nhất sẽ nổi dần lên cuối mảng như bọt khí nổi lên mặt nước.

Có thể tối ưu bằng cờ swapped. Nếu một vòng không còn đổi chỗ thì dừng sớm. Lúc đó độ phức tạp tốt nhất là O(n).

Khi nào nên dùng / không nên dùng

Phù hợp khi học lần đầu, mảng rất nhỏ, cần ổn định và code đơn giản.

Không phù hợp dữ liệu lớn vì O(n²). Một trăm phần tử khoảng mười nghìn lần so sánh. Càng nhiều dữ liệu càng chậm rất nhanh.

✓ Phù hợp khi

  • Học thuật toán lần đầu
  • Mảng rất nhỏ
  • Cần ổn định

✗ Không phù hợp khi

  • Dữ liệu lớn
  • Yêu cầu hiệu suất

Thuật toán chi tiết

Bước 1: i chạy từ 0 đến n trừ 2. Đây là số vòng nổi bọt.

Bước 2: đặt swapped bằng false ở đầu mỗi vòng.

Bước 3: j chạy từ 0 đến n trừ i trừ 2. Nếu a của j lớn hơn a của j cộng 1 thì đổi chỗ và gán swapped bằng true.

Bước 4: nếu swapped vẫn false thì break. Mảng đã sắp, dừng sớm.

Sơ đồ minh họa từng bước

Ví dụ mảng 5, 1, 4, 2, 8.

Vòng một: các cặp liền kề đổi chỗ, số 8 nổi về cuối. Vòng hai: số 5 về đúng chỗ. Vòng ba: không còn đổi, dừng sớm.

Ban đầu

Mã giả & Cài đặt C++

Có vòng ngoài, cờ swapped, vòng trong so sánh cặp liền kề, và câu lệnh break.

Trong C++, bool swapped là biến đúng hoặc sai. Nếu không swapped thì break, giúp đạt O(n) khi mảng đã sắp sẵn.

procedure BubbleSort(a[0..n−1])      // bắt đầu sắp xếp nổi bọt
  for i ← 0 to n−2 do                // số vòng nổi bọt
    swapped ← false                  // chưa đổi chỗ vòng này
    for j ← 0 to n−i−2 do            // so sánh từng cặp liền kề
      if a[j] > a[j+1] then          // cặp đứng sai thứ tự?
        swap a[j] with a[j+1]        // số lớn nổi sang phải
        swapped ← true               // đánh dấu đã đổi
      end if
    end for
    if not swapped then break        // đã sắp, dừng sớm
  end for
end procedure
void bubbleSort(int a[], int n) {          // hàm C++
  for (int i = 0; i < n - 1; i++) {        // vòng ngoài
    bool swapped = false;                  // cờ đã đổi chỗ
    for (int j = 0; j < n - i - 1; j++) {  // cặp liền kề
      if (a[j] > a[j + 1]) {               // sai thứ tự
        int temp = a[j]; a[j] = a[j + 1]; a[j + 1] = temp;
        swapped = true;                    // đã có đổi
      }
    }
    if (!swapped) break;                   // dừng sớm
  }
}

Mô hình ví dụ – Sinh viên

Sau Bubble Sort theo điểm: Lê Văn C 6.8 → Nguyễn Văn A 7.5 → Trần Thị B 8.2 → Phạm Thị D 9.0.

Ưu điểm

Rất dễ hiểu. Ổn định. Có thể dừng sớm nên tốt nhất là O(n). Không cần bộ nhớ phụ.

Nhược điểm

O(n²) khi dữ liệu lớn. Số lần so sánh và đổi chỗ nhiều. Ít dùng trong thực tế, chủ yếu dùng để học.

Kết luận

Bubble Sort dễ hiểu nhất nhưng hiệu suất kém vì O(n²). Nên học để nắm ý tưởng, sau đó chuyển sang thuật toán tốt hơn. Nhóm em xin cảm ơn thầy cô và các bạn đã lắng nghe.
