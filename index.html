02

Thuật toán chi tiết

1

Vòng ngoài

i chạy từ 0 → n−2

2

Cờ swapped

swapped ← false

3

Vòng trong

j chạy từ 0 → n−i−2. Nếu a[j] > a[j+1] → đổi chỗ, swapped ← true

4

Dừng sớm

Nếu !swapped thì break (đã sắp xong)

Mã giả & Cài đặt C++

procedure BubbleSort(a[0..n−1])
  for i ← 0 to n−2 do
    swapped ← false
    for j ← 0 to n−i−2 do
      if a[j] > a[j+1] then
        swap a[j] with a[j+1]
        swapped ← true
      end if
    end for
    if not swapped then break
  end for
end procedure
void bubbleSort(int a[], int n) {
  for (int i = 0; i < n - 1; i++) {
    bool swapped = false;
    for (int j = 0; j < n - i - 1; j++) {
      if (a[j] > a[j + 1]) {
        int temp = a[j];
        a[j] = a[j + 1];
        a[j + 1] = temp;
        swapped = true;
      }
    }
    if (!swapped) break;  // tối ưu
  }
}
Vòng ngoài: số vòng “nổi bọt”
Vòng trong: so sánh cặp liền kề
swapped: cờ kiểm tra có đổi chỗ hay không
break sớm: giúp đạt O(n) khi đã sắp sẵn

07

Ưu & Nhược điểm

Ưu điểm

  • Rất dễ hiểu và cài đặt
  • Ổn định (stable)
  • Có thể tối ưu dừng sớm → O(n) tốt nhất
  • Không cần bộ nhớ phụ

Nhược điểm

  • O(n²) – chậm với dữ liệu lớn
  • Số lần so sánh và đổi chỗ nhiều
  • Ít được dùng trong thực tế
